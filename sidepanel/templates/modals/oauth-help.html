Como Obter o Token OAuth?
O Glide usa o faturamento do Claude Code (OAuth) para que você não gaste seus créditos da API Anthropic padrão. Veja como obter o seu token em segundos:

Opção 1: Importar arquivo credentials.json (Mais Fácil)

  1. Clique no botão Importar credenciais.
  2. Navegue até a pasta:
    • Windows: C:\Usuários\SeuNome\.claude\.credentials.json
    • Linux/Mac: ~/.claude/.credentials.json
  3. Selecione o arquivo e o Glide vai extrair e configurar seu token na hora!
OU

Opção 2: Pelo Terminal

  1. Certifique-se de que já fez login no Claude Code rodando: 
    claude login
  2. Abra o arquivo .credentials.json na pasta citada acima ou obtenha o token de longa duração gerando: 
    claude setup-token
  3. Copie o token gerado (começa com sk-ant-oat01-) e cole no campo "Token OAuth do Claude Code".
